# 欢迎使用 Aluka 静态构建

Aluka 是一个用**纯 Go**实现的 JavaScript/TypeScript 运行时。

## 特色能力
- **自研引擎**：零外部 JS 依赖
- **SSG 零配置**：内置 `aluka:markdown` 解析与渲染管线
- **单命令生成**：直接执行 TypeScript 构建脚本输出多页静态 HTML
- **支持打包为独立构建工具**：可使用 `aluka build --compile` 打包为免环境独立可执行构建器
