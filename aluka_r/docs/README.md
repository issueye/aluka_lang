# aluka_r/docs

只放 **Rust 侧专属**的专项计划与设计说明。

跨实现的文档——重构计划、里程碑、架构决策记录（ADR）、性能报告、字节码规范——
一律放仓库根的 [`../../docs/`](../../docs/)，因为 Go 版与 Rust 版共享这些决策，
放进本目录会让另一半读者找不到。

判断标准：**这份文档的结论会不会影响 `aluka_g/` 的实现？**

- 会 → 放 `../../docs/`（例：`aluvm-isa-spec.md` 约束两侧，必须在共享目录）
- 不会 → 放这里（例：某个 Rust crate 的内部拆分草案、Miri 跑法笔记）

当前为空：M0 的产出物（ISA 规范、GC 选型 ADR、微基准报告）都属于跨实现文档，
直接落在 `../../docs/`。
